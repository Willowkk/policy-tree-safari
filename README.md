# 国策树 · Policy Tree

免登录、本机保存的个人 PWA。按已确认的 HTML 草稿保留四个入口：今日、My Tree 树形图标、设置、神圣座位座椅图标。支持 iPhone Safari 添加到主屏幕、离线记录和仅 JSON 备份。

[打开应用 / Open app](https://willowkk.github.io/policy-tree-safari/)

[中文使用说明](README_CN.md) · [English guide](README_EN.md)

- **国策树**：先选候选，做到后选择父节点再点亮；每天最多一次。真实连线树，节点点击展开/收起，坚持天数从点亮当天的 1 开始。修改正文保留前后记录；违反只退回相应生效分支。
- **神圣座位**：多个座位独立管理主链、预约链、判例和历史；只手动记录，无计时或预约调度。违规只清零所选链，历史保留。
- **设置**：导出 JSON、导入 JSON。兼容旧正式版本机数据与备份，按 ID 安全合并，本机版本优先，矛盾整次拒绝。

国策和座位原文不上传服务器，每位访问者使用自己的本机数据。手机和电脑不自动同步，请定期导出备份。程序缓存和主屏幕安装不能代替备份。

## 开发

```sh
npm ci
npm run dev
npm test
npm run build
```

构建包含 TypeScript 检查。GitHub Pages 通过 Actions 发布到原网址。项目子路径由 `POLICY_TREE_BASE` 指定；默认 `/`，本仓库使用 `/policy-tree-safari/`。

本地存储封装 v2 兼容读取旧 v1，首次读取不重写；下次成功保存才升级。升级后仍打开的旧标签页需更新后再写，以免旧程序覆盖新增数据。JSON 业务状态仍使用兼容的 `schemaVersion: 1`。

本轮本地验证（2026-10-18）：**82/82 测试通过**，TypeScript 与 GitHub 子路径构建通过；桌面 `390 × 844` 交互、独立链、多座位草稿/判例、JSON 实际下载与空白入口恢复、停服离线重载/新增记录、Service Worker 更新保留数据均已检查。详见中英文使用说明。

真实 iPhone 安装及系统文件分享尚未实机验证；本节不记录本轮线上发布结论。免费托管也不保证所有大陆网络都可访问。
