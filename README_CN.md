# 国策树 · Safari 单机版

[English](README_EN.md) · [产品设计](../design/v0.1/DESIGN_CN.md)

当前版本是免登录的响应式 PWA。国策和历程保存在当前设备的浏览器中，支持导出 JSON 备份及导入。运行时不上传国策数据，不依赖云同步数据库、ChatGPT、QQ 或微信登录。

在线地址：[打开国策树](https://willowkk.github.io/policy-tree-safari/)。

## 从旧网址迁移

不同网址使用独立的本机存储。先在旧网址原来的浏览器或主屏幕入口导出 JSON 备份；然后打开上述新网址，先添加到主屏幕，再从新入口导入文件。确认国策和历程完整后，日常使用新图标。旧图标仍指向旧网址，不会自动变成新地址。

分享给朋友时，每位朋友使用自己设备上的独立数据，不会看到你的国策。GitHub Pages 免费托管，但大陆网络访问需要实际测试，不能保证所有运营商或地区都可达。

## 在 iPhone 上使用

1. 联网，用 Safari 打开正式网址。
2. 打开“分享”，选择“添加到主屏幕”。如果显示“作为网页 App 打开”，保持开启，再点“添加”。[Apple 使用说明](https://support.apple.com/zh-cn/guide/iphone/iphea86e5236/ios)
3. 从主屏幕图标打开一次，保持联网，让应用完成离线缓存准备。
4. 此后在缓存可用时，可以离线查看、编辑、点亮、记录违反和复盘。

建议先添加到主屏幕，再开始正式记录。Safari 标签页和主屏幕 App 可能使用分开的存储空间；如果原来的记录没有出现，从原入口导出备份，再在新入口导入。添加主屏幕不等于备份，不需要 Apple 开发者会员或每 7 天续签。

Mac 可以直接通过浏览器访问，也可以在支持的 Safari 中添加到程序坞。[Mac 网页 App 说明](https://support.apple.com/zh-cn/104996) Windows 可以使用现代浏览器访问相同网页；各设备的数据分别保存。

## 日常流程

- 有空时填写“名称＋规则”，将多条国策放入待选库；也可以保存未完成的草稿。
- 每天从待选库选择一条“今日尝试”。实践成功后确认挂载位置，再正式点亮。
- 每个本地数据空间按 **Asia/Shanghai（北京时间）00:00** 换日，每天最多点亮一条，不要求每天都点亮。当天点亮后又退回，也不返还额度。
- 待选少于 5 条时显示应用内补库提示；草稿、今日尝试和已退回不计入待选。
- 主动记录违反时，先查看影响范围。违反节点及其全部生效后代退回，祖先和兄弟分支保留，历史也保留。
- 可以写自由文本复盘，调整后再加入待选库。

本地保存成功即正式生效，离线时也相同；没有等待云端确认的步骤。保存失败会显示错误，不能把未保存的操作视作完成。没有定时提醒、日历提醒或系统推送。

## 导出与恢复

在“设置”中选择“导出备份”，保存生成的 JSON 文件。iPhone 若打开系统分享面板，可选“存储到‘文件’”；若下载文件，请到 Safari 下载列表或“文件”App 中找到并妥善保存。建议在集中修改后、换设备前、清除网站数据前各导出一次。

恢复或换设备时，在目标入口打开“设置 → 导入备份”，选择 JSON 文件并确认。

导入按记录 ID 合并：

- 新的国策和历程加入当前数据。
- 已存在的同 ID 国策及事件保留当前内容，不用备份中的旧版本覆盖。
- 文件格式、树关系或同一天点亮记录存在不兼容时，整次导入被拒绝，当前数据保留；先查看错误说明。
- 旧版云端 PWA 的兼容快照可以迁移已保存的数据；备份里的旧待同步操作不会自动重放，待确认点亮不会自动成为生效国策，提醒设置也不迁移。

因此，导入是补充和恢复入口，**不是双向同步**。在电脑修改过同一条国策后导回 iPhone，不会覆盖 iPhone 上已有的同 ID 国策。建议长期选一个主要使用入口；向空数据空间导入完整备份最适合换机恢复。

备份文件含国策和复盘的原文，请存放在自己信任的位置。把文件放入 iCloud Drive 等位置由你自行选择，应用不会自动上传。

## 本地保存的边界

同一浏览器、同一网址、同一用户场景下的普通标签页共享本地记录。不同设备、不同浏览器、无痕窗口、不同网址及主屏幕 App 可能属于不同数据空间，不会自动同步。每日点亮上限也只在当前本地数据空间内执行，不能跨独立副本验证。

首次访问或离线缓存未准备好时，需要联网。清除网站数据、移除存储或系统回收数据后，没有服务器副本可以找回；需要导入先前导出的文件。[WebKit 存储说明](https://webkit.org/blog/14403/updates-to-storage-policy/)

公共网址提供应用程序；其他人打开同一个网址会看到自己浏览器的数据，不会读取你的国策。联网加载与检查更新仍会向托管服务请求程序文件，运行时不发送国策内容。

应用不收取会员费，也没有付费云同步依赖。静态托管服务仍可能改变政策或停止服务，不承诺网址永久免费、永久可访问，浏览器本地存储也不是永久保管。

## 更新

发现新版本时，由你选择“立即更新”或“稍后”。先保存当前编辑，再更新；不会为了更新强制刷新填写中的页面。应用缓存和个人数据分别处理，更新前仍建议导出备份。

## 本地运行与构建

进入 `safari/` 后运行：

```sh
npm install
npm run dev
```

其他命令：

```sh
npm test
npm run build
npm run preview
```

`npm run build` 生成静态目录 `dist/`，可部署到支持 HTTPS 的静态托管。离线缓存使用 Service Worker，开发服务器不代表生产离线行为，应以构建后的预览和实际 HTTPS 网址验证。不要直接双击 `dist/index.html` 当作安装入口。

本目录是当前主版本；`../web/` 与 `../wechat/` 保留为历史实现。已通过 56 条自动化测试，并在桌面浏览器验证创建、点亮、重载和停服后的离线启动。尚未在真实 iPhone Safari 上测试系统分享和主屏幕安装。
